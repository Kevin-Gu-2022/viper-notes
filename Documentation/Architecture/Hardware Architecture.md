- PoDL interface has an absolute maximum range of 100V
- LTC9111 (PoDL controller) input voltage range is 2.3V to 60V with an absolute maximum of 100V
- LT8304 Isolated flyback controller that steps down to 5V needed for Arduino Portenta X8 also has wide input range, up to 100V
- Capcitors and Mosfets are all rated for 100V too
- As an added protection 100uF filtering capacitor
