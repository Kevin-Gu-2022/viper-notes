- Ethernet protocol that provides both power and data transfer over a dingle unshielded twisted cable pair
- Includes PoDL (Power over Data Lines)
- Up to 100 Mbps
- Multi-drop: Nodes can be wired in a bus topology, similar to CAN. Saves wires, cost, and allows daisy-chaining
	- Standard Ethernet bus uses a star topology, which needs separate cables for each device
## PoDL
- Split into the PSE (Power Supply Equipment) and PD (Powered Devices)
- Generally, there is a negotiation stage initially to determine safe power, but this can be skipped
