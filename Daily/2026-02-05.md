#### Remove udev rule notes from [[Yakut]]

>[!note] 
>Don't do this actually, just use the yakut startup script - does it all automatically (udev rules not great as not always use same transport)

Can set up udev rule to automatically register Babel to can0. udev rules are sequences of actions that are performed on events like peripheral updates (e.g. device being plugged in)
```bash
sudo nano /etc/udev/rules.d/99-zubax-babel.rules
```
Add following into file:
```bash
# Map Zubax Babel to can0 and bring it up
ACTION=="add", SUBSYSTEM=="tty", ATTRS{idVendor}=="1d50", ATTRS{idProduct}=="60c7", RUN+="/usr/bin/slcand -o -c -s8 /dev/%k can0", RUN+="/bin/ip link set can0 up"
```
May encounter race conditions upon start-up where `ip link set` command triggers before `slcand` finished initialising device, in which case a small 1 second delay can be added in between.

Then:
```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```
